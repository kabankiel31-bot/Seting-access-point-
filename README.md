# Seting-access-point-
1. Siapkan Ruter
Siapkan ruter dengan menghubungkan perangkat tersebut ke stopkontak. Letakkan ruter di tempat yang tidak akan mengganggu aktivitas di dalam ruangan tersebut.
2. Sambungkan Semua Perangkat
Setelah itu, sambungkan semua perangkat, seperti adaptor AC/DC ke Access Point dan soket listrik. Lalu, gunakan kabel ethernet untuk menghubungkan Access Point ke ruter yang dimasukkan ke port LAN. Gunakan kabel ethernet juga untuk menghubungkan ruter dengan komputer.
3. Konfigurasikan Access Point
Sekarang, lakukan konfigurasi pada Access Point menggunakan komputermu. Gunakan alamat IP yang tercantum dalam buku manual untuk melakukan konfigurasi, seperti memasang kata sandi atau lainnya. Umumnya, alamat IP yang digunakan adalah 192.168.0.1 atau 192.168.1.1. Masukkan alamat IP tersebut ke kolom alamat URL di perangkatmu.
4. Selesai
Sekarang, kamu sudah selesai menyiapkan Access Point dan dapat menikmati perangkat tersebut yang dihubungkan ke komputermu.
